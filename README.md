# Los Angeles Catering Experts

A modern React + TypeScript + Vite application empowering event hosts and corporate coordinators in Greater Los Angeles with transparent catering cost calculations, verified caterer directory listings, and dedicated taco catering resources.

## Features

- **LA Catering Estimator**: Instant budget estimates by event type (Corporate, Weddings, Private Parties, Taco Bar) with per-guest rates, guest count sliders, add-ons (staff, bartending, rentals), and quote generation.
- **Interactive Taco Portion Calculator**: Calculates taco totals, protein quantities (carne asada, pollo asado, al pastor), tortilla packages, and side portions based on guest counts and appetite levels.
- **Yelp-Style Dual Search Bar**: Dual-field search ("Find" cuisine/service + "Near" LA city or zip code) plus quick filter tags.
- **Catering Companies Directory**: Comprehensive listing of vetted Los Angeles caterers with category filtering (Weddings, Corporate, Tacos, Film Sets, Charcuterie), direct website links, and listing claim portal.
- **Taco Catering Guide**: Dedicated Los Angeles taco catering directory filtering mobile taco carts, food trucks, and event buffets.
- **Editorial & Evaluation Standards**: 4-pillar evaluation criteria (Price Transparency, Food Quality, Verified Feedback, Precision Tools).
- **Interactive Forms**: Lead inquiries, "List Your Business / Claim Listing", and California CCPA "Do Not Sell or Share" request portal.
- **Compliance & Privacy**: Cookie consent banner, CCPA compliance, and Terms of Use.
